# 榜单、默认静音与播放页操作

## 行为约定

- 榜单顺序与源站公开导航一致：热播榜 `hot`、推荐榜 `recommend`、飙升榜 `potential`。每榜展示公开接口返回的前 20 条，使用返回的排名和指标，不在客户端重新排序。
- 榜单条目优先读取 `video_id`，兼容仅含 `id` 的旧格式；无效编号不生成点击入口。详情和播放继续使用现有流程。
- 每次新加载页面默认静音，首页和详情播放器共享本次会话的声音选择；主动点击声音按钮后才能开声。暂停、继续、切集和切换页面不会自行开声；重新加载或从浏览器历史缓存恢复时重新静音。
- 旧 `hg_muted` 持久记录不再影响起播，新的声音选择不写入持久存储；地址、密钥、历史和其它设置沿用原有存储。
- 播放页显示操作栏时，轻点视频画面、黑色留白或播放器背景立即收起整组操作；隐藏后再点只显示操作，不改变播放状态。按钮、进度条、菜单及锁定层保留各自操作。四秒闲置自动隐藏仍保留，桌面鼠标移动继续沿用原有唤出方式。
- 中央播放/暂停按钮沿用现有 72px 半透明圆形及 32px SVG；正常显示操作栏时可见，隐藏和锁定时隐藏。没有新增第二套播放入口。

## 原因与源站边界

热播榜返回 `video_id`，旧页面读取 `id` 后会请求 `/api/videos/NaN`，得到 HTTP 400“无效的 ID”。原来另外四个固定参数 `like/view/weekly/monthly` 均返回“榜单不存在”。

源站导航实际为 [热播榜](https://huangguoai.com/ranks/hot/)、[推荐榜](https://huangguoai.com/ranks/recommend/)、[飙升榜](https://huangguoai.com/ranks/potential/)。三个公开接口 `/api/ranks/hot`、`/api/ranks/recommend`、`/api/ranks/potential` 都返回 `data.items`，条目使用 `video_id`。调查时源站网页与公开 API 的排序和指标名称存在差异；本实现跟随三类入口并展示公开 API 数据，不承诺与源站服务器渲染页面逐项同序。

用户提供的中央按钮截图，进度条左侧仍显示“播放”文字，与 `d632128` 之前的控件结构一致。当前本地代码和实际页面的中央按钮正常。截图不能单独证明是旧部署还是旧缓存；没有访问或改动用户手机、运行中的服务器来判断其实际资源版本。

## 实现与维护

逻辑位于 `local_ext/audio_patch.js`、`rank_patch.js`、`player_controls.js` 和 `player_patch.js`，由 `tools/apply_local_patches.py` 向 Web 与 Android 页面插入受控标记钩子。剥离标记块后，两份 HTML 的上游正文与本次修改前一致。

静音初始化早于 `loadHome` 和 `handleDeepLink`，避免先启动播放再补设静音。榜单切换使用原有请求代次，迟到的旧响应或旧失败均不会覆盖当前榜单；按钮保留选中态和 `aria-pressed`，列表加载标记 `aria-busy`，条目支持 Enter/空格打开详情。

## 本地验证（2026-11-15）

环境：Windows，独立 Python Web `127.0.0.1:18081`、代理 `127.0.0.1:18080`，Chrome 无头浏览器，真实业务页面和上游数据；封面解密使用 Git 自带 OpenSSL。未替换 `fetch`、详情接口、播放接口或媒体方法。手机验证为 Chromium 的 390×844 视口及触屏输入，桌面为 1280×800；不代表 iPhone/Android 原生真机或 Safari 验收。

默认离线命令 `python tests/run_all.py`：114 个用例，93 通过、21 因在线或平台条件跳过、0 失败、0 错误；另有 6 个浏览器测试类按默认开关整体跳过。未运行 `--ui` 或完整 `--online` 套件。

新增 `tests/test_rank_audio.py` 执行真实业务函数与本地模块的回归：榜单参数、编号、指标、旧请求竞争、静音默认值、暂停/继续、会话共享、重新打开及启动时序。修复前这三项失败，修复后全部通过。另补充可选浏览器回归，覆盖视频、容器和背景的即时显隐及播放状态不变；该可选用例未作为默认套件运行，实际页面已单独检查等价事件链。

实际页面最终 19 项检查全部通过，结果记录在本机 `.test-tmp/rank-audio/results.json` 和同目录 PNG 中：三个榜单各 20 条及首条详情编号一致；三个榜单首条的真实媒体均加载并开始推进，且保持静音；中央按钮显示、暂停/继续、主动开声、重新进入、留白点击及桌面布局均通过。截图属于本机验收证据，不随代码提交。初次验证脚本因未滚动到详情底部按钮而中止；改正后重验。另一轮使用鼠标验证触屏显隐时触发了原有鼠标移动唤出，改用触屏输入后重验，不将早期中止结果算作最终通过。

预览工具的点击与截图发生超时，浏览器连接工具也不可用，最终验证改用项目现有 CDP 工具连接独立 Chrome；未运行模拟业务页。测试结束后关闭本次创建的浏览器和两个服务，未影响已有端口或进程。
